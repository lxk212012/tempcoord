# TempCoord

**隐私优先的匿名社交元宇宙**

TempCoord 是一个专注于隐私保护的开源社交项目。

用户可以通过创建匿名数字人物，在完全掌控隐私的前提下，进行私密互动和社交探索。

## 核心特点

- **强隐私保护**：用户自主控制所有数据和可见权限，平台无权查看隐私内容
- **临时坐标**：可随时创建加密私密空间，双向确认准入，互动结束后自动断开
- **匿名身份**：无需实名，无需手机号，支持隐身模式
- **去金融化**：零代币、零资产交易，回归纯社交本质
- **轻量普惠**：移动端优先，低门槛接入

## 当前状态

项目处于早期开发阶段，正在逐步推进中。

目标是先做出最小可用版本（MVP）：数字人物 + 个人空间 + 临时坐标。

白皮书和详细路线图后续会陆续更新。

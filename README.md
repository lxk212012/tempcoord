# TempCoord
> 隐私优先的匿名社交元宇宙

TempCoord 是一个专注于**隐私保护**的轻量级社交元宇宙项目。
用户可以通过创建匿名数字人物，在完全掌控数据与可见性的前提下，进行私密互动和社交探索。

---

## ✨ 核心特点
- 🔒 **强隐私保护**
  用户自主控制所有数据和可见权限，平台无法查看任何隐私内容，通信全程加密。
- 📍 **临时坐标互动**
  可随时创建加密私密空间，通过临时坐标建立连接，仅双向确认后可准入，互动结束后坐标自动失效、断开连接，不留可追溯痕迹。
- 🕵️ **匿名身份**
  无需实名，无需手机号，支持隐身模式，让你以纯粹的数字身份自由社交。
- 💸 **去金融化**
  零代币、零资产交易，回归社交本质，拒绝金融投机与炒作。
- 📱 **轻量普惠**
  移动端优先，低门槛接入，无需高性能设备，随时随地开启隐私社交。

---

## 🛠️ 技术栈
- **前端**：React + TypeScript（轻量化、响应式适配移动端）
- **后端**：Vercel Serverless Functions（无服务器架构，降低运维成本）
- **合约层**：Solidity（以太坊/兼容链），核心合约开源可验证：
  - `PrivacyConstitution.sol`：隐私规则与治理宪法
  - `GlobalConsensusBanned.sol`：全局封禁与合规共识
  - `CoreRegistry.sol`：模块注册与地址管理
- **隐私方案**：端到端加密 + 临时坐标失效机制
